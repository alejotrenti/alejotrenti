## 🧑‍💻 Sobre mí

Soy técnico en informática y estudiante de **Licenciatura en Ciencia de Datos** en Argentina 🇦🇷.

Me especializo en construir **productos de datos completos**: desde la extracción y transformación de datos, hasta el modelado, análisis y visualización en dashboards interactivos.

Me apasiona transformar datos crudos en **insights accionables** y construir herramientas que ayuden a tomar decisiones basadas en evidencia.

## 🚀 Featured Projects

### 🔮 Future Skills Engine
> *Data platform para analizar y predecir tecnologías emergentes*

Plataforma de inteligencia tecnológica que integra múltiples fuentes de datos (Stack Overflow Survey, GitHub API, arXiv) para detectar tendencias y crecimiento de habilidades.

**Stack:** `Python` `PostgreSQL` `Apache Airflow` `Docker` `Streamlit` `GitHub API` `arXiv API`

**Arquitectura:**
- `Bronze` → Raw data ingestion
- `Silver` → Data cleaning & transformation
- `Gold` → Curated analytics tables
- `Dashboard` → Interactive visualizations

---

### 🏥 Parkinson Disease Prediction
> *Modelo de machine learning para detección temprana*

Modelo de clasificación basado en características biomédicas para predecir la enfermedad de Parkinson.

**Stack:** `Python` `Scikit-learn` `Pandas` `XGBoost` `Streamlit`
