## Featured Projects

### Future Skills Engine
> *Data platform para analizar y predecir tecnologías emergentes*

Plataforma de inteligencia tecnológica que integra múltiples fuentes de datos (Stack Overflow Survey, GitHub API, arXiv) para detectar tendencias y crecimiento de habilidades.

**Stack:** `Python` `PostgreSQL` `Apache Airflow` `Docker` `Streamlit` `GitHub API` `arXiv API`

**Arquitectura:**
- `Bronze` → Raw data ingestion
- `Silver` → Data cleaning & transformation
- `Gold` → Curated analytics tables
- `Dashboard` → Interactive visualizations
